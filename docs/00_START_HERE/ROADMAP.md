# Roadmap

## Phase 0 — Repository foundation

- Normalize documentation
- Establish architecture decisions
- Create machine-readable project brain
- Define implementation order

## Phase 1 — Personal control plane

- Local authentication or single-user access
- Project configuration
- Provider credentials
- Workflow dashboard
- Task history and cost tracking

## Phase 2 — SEO intelligence MVP

- Keyword import and discovery
- SERP snapshots
- Intent classification
- Competitor and content-gap analysis
- Opportunity scoring
- Topic clustering

## Phase 3 — Content factory MVP

- Research evidence store
- Content briefs and outlines
- Writer and editor agents
- Fact-checking
- Deterministic QA gate

## Phase 4 — Publishing and feedback

- First CMS connector
- Scheduled publishing
- Search Console ingestion
- Ranking, traffic, CTR, and conversion feedback
- Content refresh recommendations

## Phase 5 — Scale only when needed

- More workers
- Dedicated analytics storage
- Multi-project automation
- Additional CMS and data-provider adapters
