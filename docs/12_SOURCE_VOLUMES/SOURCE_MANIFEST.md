# Historical Source Manifest

The historical documentation generated before repository normalization has been deduplicated and grouped into ten thematic volumes:

1. Product Foundation
2. Architecture and Platform
3. Database, API and Contracts
4. AI Platform and Agents
5. SEO Intelligence
6. Content Factory
7. QA, Security and Enterprise
8. Infrastructure and Operations
9. Implementation and Roadmap
10. Miscellaneous Reference

Exact duplicate documents were removed. Source paths and conflicting drafts are retained inside the consolidated archive for provenance. Canonical implementation decisions remain in `docs/00_START_HERE` through `docs/11_MACHINE`.

The compressed source bundle is generated from 1,222 unique Markdown documents and is intentionally kept separate from canonical specifications to avoid overwhelming Codex context loading.
