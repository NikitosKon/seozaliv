# Content Factory

Documents merged: **132**

This volume consolidates research, source collection, citations, briefs, outlines, drafting, editing, fact checking, metadata, FAQ, schema, localization, media prompts, versioning, approval, revision, publication, and content-metric drafts.

## Canonical workflow

Approved opportunity → research dossier → evidence map → content brief → outline → draft → editorial pass → claim verification → SEO and conversion optimization → QA → approval → preview → publication → analytics feedback.

## Evidence and provenance

Every external claim should be represented as a structured claim with source references, retrieval time, confidence, and verification state. Sources are snapshotted or fingerprinted where permitted so later updates can detect stale evidence.

## Content artifacts

Content pages are immutable versions connected by lineage. Briefs, outlines, drafts, editorial passes, QA reports, approvals, and publications remain separate artifacts rather than being overwritten in place.

## Quality requirements

Avoid filler, unsupported certainty, generic AI phrasing, duplicated sections, fake quotations, and fabricated citations. The output must satisfy the selected search intent, cover required entities, provide practical user value, and contain a relevant next action.

## Publication

CMS connectors transform the canonical page model into provider-specific formats. Publication uses previews, idempotency keys, remote-state reconciliation, scheduled execution, and rollback or version restoration where the CMS permits it.
