# Miscellaneous Reference

Documents merged: **216**

This volume accounts for source drafts that did not fit cleanly into a single canonical domain, including generated catalogs, examples, generic templates, metrics, checklists, manifests, and early placeholder specifications.

## Preservation policy

Useful decisions from these drafts should be migrated into canonical documents only after review. Generic repeated placeholder text is not authoritative. Machine-readable registries and executable contracts take precedence over prose when they describe the same released version.

## Context-loading policy

Codex and other agents should not load this volume by default. Use it only for targeted historical lookup. Default context should start with `docs/00_START_HERE`, the relevant canonical Bible, and the files directly affected by the task.

## Conflict resolution

When historical drafts disagree:

1. prefer the personal-edition project manifest;
2. prefer later explicit decisions over generic earlier templates;
3. prefer working code and executable schemas over prose;
4. record material architecture changes as ADRs;
5. preserve the old decision in Git history rather than duplicating it in canonical files.
